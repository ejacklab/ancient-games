Full findings: `FINDINGS.md` (same folder). Status: **negative result — do not rebuild the selector.**

**Answer.** The biology is real but does not add a mechanism the method lacks. The designed "whale pod mode selector" (lunge / dive / driver-and-barrier / elder takeover, first-match over nine features) maps one-to-one onto rules already in the method: the main-agent default, hand-off only for context room or a different kind (3.2), the maker-checker row, and the tier exit (3.5). The critic's verdict: decoration, fails Rule 2, drop the selector.

**Confidence.** Mostly *reported*: only about 4 of 22 strategies came from a primary source. Cross-checked: orca wave-washing took 12 of 16 Weddell seals (Visser 2008). The "about 50% success" for orca beach-stranding is from a content-farm site; do not use it. No source gives a cooperate-versus-solo trigger for any species; the decision rules were the researchers' inference.

**Where the analogy breaks.** Unit economics are inverted (a whale's body is a fixed cost; an agent hand-off costs tokens and context); whales share an ocean, agents share only files; the behaviours are learned over generations and ours is coded in a day.

**One idea worth keeping.** First-match ordering forces one named reason per piece for its node boundary. As a plain checklist column in the 3.2 piece table, not a selector.

**Smallest experiment (pre-register, not run).** Take 3–5 real pieces of different kinds; write the plain method's decision for each; run the selector on the same facts; if it never differs, drop it.
