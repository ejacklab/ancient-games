# N2 — Add two checks to tools/memory_index.py (coder)

You change one existing script so that it meets two new requirements. Tests that define "done" are already written and
frozen; you make them pass.

## The spec (read first)

- `docs/index-md/REQUIREMENTS.md`: **B2.3** (an `id` must be in W1.1's form `DD-MM-xxxxxx-YYYY`: two digits, `-`,
  two digits, `-`, six lowercase letters or digits, `-`, four digits), the new **B2.7** (no line starting `<<<<<<<` or
  `>>>>>>>`), **B2.5** and the **B2 Fails if**, and **G4.2**.
- `docs/index-md/DESIGN.md` step 5: both are **errors for every entry**, in every status (active, superseded and
  retired), in write mode and in check mode.

Points the tests hold you to:
- The id form is checked against the whole value, after B2.1 strips spaces and quotes. Nothing may follow the four
  digits.
- ASCII digits and letters only. Python's `\d` and `str.isdigit()` also match non-ASCII digits, so do not use them.
- The form only: `31-02-a1b2c3-2026` passes. Do not check that the day and month make a real date.
- A marker is a line that **starts** with `<<<<<<<` or `>>>>>>>`, anywhere in the file: in the header or in the body.
  A line that is only `=======` is not an error.
- Errors print as `<file>: <problem>`, write nothing, and exit 1, like the script's other errors. No traceback on any
  input.

## What you may change

- `tools/memory_index.py`
- `tests/test_memory_index_unit.py`: update the unit tests the change breaks, and add unit tests for the two new
  checks.

Do **not** change `tests/test_memory_index.py` (the frozen acceptance tests), anything in `docs/`, `.githooks/`,
`CLAUDE.md`, `AGENTS.md`, or git config. Do not create `project-memory/`. Do not commit. Do not read `runs/`.
Standard library only. Match the script's existing style, naming and comment density; keep the change small.

## Done means

```
env -u NO_COLOR python3 -m pytest -q tests/test_memory_index.py tests/test_memory_index_unit.py
```

passes in full, and the full suite still passes:

```
env -u NO_COLOR python3 -m pytest -q
```

If a frozen test contradicts the spec, do not change the test and do not bend the code around it. Write
`CONTRADICTS <test name> <criterion id>` with both sides quoted, and stop.
