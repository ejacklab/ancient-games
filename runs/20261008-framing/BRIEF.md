# Is this framing right? The Ancient Games is ONE framework.

The repo's `CLAUDE.md` currently describes the project as two separate things:

- "The main product is `.claude/skills/workflow-design/`: a skill that designs workflows."
- "`ancient_games/` — the framework: a referee for agent work. Five stages: Gate → Guard → Corroborate → Filter → Prove."

The author (EJ) says this is **wrong and outdated**, and corrects it:

> The Ancient Games is **one framework**. The workflow-design method (the 8 steps that turn an incoming task into a
> designed workflow) is a **part** of it — not a separate "main product". The referee (`ancient_games/`) is another
> part. The knowledge (docs, skills, templates) is what both parts use. A task comes in → the method designs the
> workflow → the referee checks the work → the feedback loops back into the method. One system.
