## 1. Dominant patterns now
Anthropic's taxonomy — chaining (sequential), routing/handoffs, parallelization (sectioning = map–reduce, voting), orchestrator–workers, evaluator–optimizer — is still the cited canon, "nothing retracted" ([Building Effective Agents, 2024-12-19](https://www.anthropic.com/research/building-effective-agents); [2026 status map](https://raw.githubusercontent.com/ThibautMelen/agentic-ai-systems/main/foundations/what-changed-2026.md)). Its 2026 update keeps only three: sequential, parallel, evaluator–optimizer ([Anthropic, 2026-03-05](https://claude.com/blog/common-workflow-patterns-for-ai-agents-and-when-to-use-them); [coverage 2026-03-05](https://blockchain.news/PostAMP?id=anthropic-ai-agent-workflow-patterns-enterprise-guide)). OpenAI ships two ownership patterns, handoffs and agents-as-tools ([Agents SDK docs](https://developers.openai.com/api/docs/guides/agents/orchestration)). Emerging: event-driven DAG-plan-and-execute vs ReAct ([arXiv 2606.20058, 2026-06-18](https://arxiv.org/abs/2606.20058)), self-organizing "incremental graph evolution" that spawns nodes on demand ([SAIGE, arXiv 2609.19759, 2026-09-17](https://arxiv.org/abs/2609.19759)), flat vs hierarchical ([arXiv 2609.14767, 2026-09-13](https://arxiv.org/abs/2609.14767)), context engineering (Anthropic, Sept 2025), loop→graph engineering ([Rather Labs, 2026-07-31](https://ratherlabs.com/blog/graph-engineering-multi-agent-ai-systems); [Tencent, 2026-07-30](https://cloud.tencent.com.cn/developer/article/2740983)). *CONFIRMED* these are named; *GAP*: no source ranks their market share.

## 2. Is the DAG still the model?
No, not as default. Anthropic's rule is "default to sequential, move to parallel only when latency bottlenecks independent tasks, add loops only when first-draft quality demonstrably falls short" (2026-03-05). LangGraph itself now offers a **Functional API** (imperative, sequential, linear workflows) beside the Graph API, which it reserves for branching, merge points and shared state ([LangChain docs, retrieved 2026-10-08](https://docs.langchain.com/oss/javascript/langgraph/choosing-apis)). So: sequential first, DAG when it earns it — *CONFIRMED*. DAG is not dead: LangGraph reports 100k+ production apps and lowest token cost for well-specified workflows (*INFERRED* — secondary report, [2026-04-05](https://agentmarketcap.ai/blog/2026/04/05/langchain-state-of-agent-engineering-2026)).

## 3. Does 3.6 still earn its place?
Yes. 3.0–3.5 do not answer *what depends on what*, *what may not see what*, or *where the join is* — and those are what break: multi-agent wins only on "long-horizon tasks with sparse dependencies," single-agent wins on "tightly coupled, sequential workflows" (SAIGE, 2026-09-17); unverifiable revision loops measurably degrade output (flat beat hierarchical, d=0.42, p=0.009, 2026-09-13); verifier visibility changes results more than model choice (Rather Labs, 2026-07-31). 3.6 is a formality only if its output is a picture.
