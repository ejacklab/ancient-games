## Other findings

1. Screenshot and HTML are different builds (item 2): the screenshot has a Green button, `index.html` does not. Either the file is stale or the screenshot came from another version. Which one is current cannot be told from these files (all five PNGs and `index.html` have the same modification time, 15:14:37).
2. Muted text is low contrast on the default Sepia: `--muted #8a7560` on `#f4ecd8` = 3.72:1, used for the 12px header, 11px kind tag, 14px source/label lines and the 12px "%" footer (below 4.5:1). White 5.3:1, black 6.1:1, green 4.48:1. The inactive dots (`--rule #d9caa9`) are 1.38:1 on sepia: faint, and they are the tap targets for jumping.
3. Text in the supplied content shows visible joins where a space seems to be missing, in `index.html` itself (not a rendering fault): "roughly500 years" (Sun Tzu, same phrase in Laozi reads "roughly 500 years"), "Confucius, then51, travelling" (Laozi), "in it吳王闔廬 says" (Sun Tzu). These look like dropped characters/spaces in the source copy; worth a look against the source list (R5).
4. Person-2 screenshot: the URL breaks inside a percent-escape (`%E5` / `%8F%B2`). Contained, but hard to read; a link shown as text could be shortened to its host.
5. The last text line sits right on the footer rule with no gap (all four `person-*.png`, bottom). Normal for a scrolling view, but tight.
6. The person's name appears twice on the first screen of each panel (header line and the H1 right below it, ≈50px apart).
7. Panels are long continuous scrolls (22,000–38,000 px = about 25–42 screens at 915px); the "%" footer is the only place cue. That is the design (R3, R4.4); noting it only because there is no way to jump inside a person.
8. Fonts come from Google Fonts (`<link>` to fonts.googleapis.com). Offline, the page falls back to Georgia / system CJK serif and still reads, but the Literata look and the Hyperlegible choice would change.
9. The three Wikisource `<a>` links open in the same tab (no `target`), leaving the reader; position is restored from localStorage, so it is recoverable.
