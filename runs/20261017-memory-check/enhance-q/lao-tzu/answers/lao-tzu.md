## Costs and risks

- **1 — warning for `could not run`:** costs one filter change (`warn.ts:46`), one acceptance test on a fixture already built (`acceptance.test.ts:108`, the shallow clone), and one amendment to R2's fails_if — a spec change with the owner as the decider. Risk: it breaches R2's "nothing else" as written until the amendment lands, and a `could not run` line is more alarming than a `fail` line when the cause is a shallow clone; say so in the line's words, from the id and the category, never the evidence prose (the shape `fix-2.result.md:17` fixed, my #14 — 不自見故明: display nothing that is not the finding).
- **2 — install the hook:** the only price is the owner's yes plus one entry in `~/.claude/settings.json`. Risk: it fires in **every** git project, so every project without an `AGENTS.md` gets one line at every session start (`settings-diff.md:34–35`) — the owner must accept that noise, or the hook checks nothing at all. Risk: a 20s timeout on a long history kills the hook, and `2>/dev/null || true` turns that into silence (my #6's 慎終如始 does not help a process that was killed).
- **3 — say each absence once:** costs an amendment to R1 (one line per id becomes one group line per absent location, ids still listed) and a `rows()` regex touched in four places (`acceptance.test.ts:13`, `review.test.ts:15`, and the two helpers in the first). Measured target: the report on this repository under 9 KB (from 21,173), every one of the 75 ids still present.
- **4 — a real project:** costs EJ's time, not the tool's; F3 keeps it read-only (`smoke-report.md:23`), and `--project` on a path outside this repository is already tested (`acceptance.test.ts:43,45`). Risk: **the report is trusted too early.** A first real run that finds nothing confirms almost nothing; one that finds a lot may mostly find what the fixtures never had. Conditional: if no project is named, skip it rather than widen the fixtures (a fixture written to match the tool is not evidence — my #8).
- **5 — the counts line:** costs one test and one line. Risk: none I can name; it is arithmetic in the owner's own product. My #7 — 民之從事，常於幾成而敗之，慎終如始 — the enhance step fails at its last mile, and this is the last mile.
