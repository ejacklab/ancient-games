## Where 孫子兵法 does not help

- **4.7, the ledger header drifting from the gate's field list.** The nearest line in the notes is 形名 — 凡治眾如治寡，分數是也；鬥眾如鬥寡，形名是也 — read as "forms and their names", a shared vocabulary matching commands to formations (CANONICAL #9, and the notes are explicit that it is **RECALLED**, claude only, single-source, and the weakest-evidence principle in the set). Even if it were verified, it is about soldiers agreeing on signals, not about which string a JSON key holds. CANONICAL says so directly: the text "gives no division of labour, no schema, no handoff rule … Treating 孫子兵法 as a source of workflow mechanics is a category confusion."
- **2.5, the accuracies published without a denominator.** The tempting line is 先知者，不可取於鬼神，不可象於事，不可驗於度 — foreknowledge "cannot be verified by reckoning" (用間篇, VERIFIED) — and using it here would be a misreading the notes already block twice: CANONICAL #15 records that 度 is traditionally calendrical reckoning and "should not be read as a distrust of empirical measurement", and deepseek #13 says the same. A published percentage needs a denominator because arithmetic works, not because a war text disapproved of divination.
- **2.2, the corpus with no challenger arm.** The line that looks like support is 以正合，以奇勝 — engage with the orthodox, win with the extraordinary (勢篇, VERIFIED, CANONICAL #8) — and it does say a workflow should carry a bounded alternative to its default. But it says nothing about whether a *test* executed the rule that governs the alternative, and claude #7 is careful that the project's 20% challenger rule "has the same shape, which is a parallel and not evidence for it". This is where the text will be most misapplied, which is why I name it: it reads as cover for a coverage gap. The honest statement of the defect is experimental, not strategic — an untested arm of a test is not a missing 正 or a missing 奇.
