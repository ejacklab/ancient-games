## 2. why the three C17 tests cannot pass while this node runs

test/round3.test.ts:839-842 throws before any assertion when ps shows a line matching /opencode\s+run/. The engine
running this node is launched exactly that way, and so is the runlog.py wrapper that launched it:

Nothing under src/ can change that, and the third test would fail on its assertion even if the precondition were
skipped (it expects exit 0, while this node's own engine line is a genuine concurrent opencode run). The behaviour
the three tests pin is implemented and verified in section 3 with a stand-in process table.

## 3. C17 probe — the three shapes of test/round3.test.ts, with ps replaced by a stand-in

the stand-in prints the guard's own process line and its parent's line (both naming an engine), plus one
other process when FAKE_SLEEPER is set:

  #!/bin/bash
  # A stand-in for ps: only the two processes of the guard's own line and, when asked, one other process.
  cli_pid=$PPID
  parent_pid=$(awk '{print $4}' /proc/$cli_pid/stat)
  printf '%s %s\n' "$cli_pid" 'bun /x/tools/harness-guard/src/cli.ts lint opencode run "own line"'
  printf '%s %s\n' "$parent_pid" 'bash -c bun cli.ts lint opencode run "parent line"'
  if [ -n "$FAKE_SLEEPER" ]; then
    printf '%s %s\n' "424242" "bash -c sleep 30; : opencode run review $FAKE_SLEEPER"
  fi

(1) another process whose line contains harness-guard still counts for lint:
  $ FAKE_SLEEPER=tools/harness-guard/SPEC.md-x PATH=/tmp/opencode/fakebin:$PATH bun src/cli.ts lint 'opencode run "second task"'
  fail trap:opencode-parallel: two opencode runs started at once can fail with 'database is locked' Fix: run opencode calls one after another, never in the background or in parallel
  exit=1

(2) the same for the hook adapter:
  $ echo <PreToolUse payload> | FAKE_SLEEPER=... bun src/cli.ts hook claude
  {"hookSpecificOutput":{"hookEventName":"PreToolUse","permissionDecision":"deny","permissionDecisionReason":"trap:opencode-parallel: two opencode runs started at once can fail with 'database is locked' Fix: run opencode calls one after another, never in the background or in parallel"}}

(3) the CLI's own process and its parent are dropped even when their lines name an engine:
  $ PATH=/tmp/opencode/fakebin:$PATH bash -c "bun src/cli.ts lint 'opencode run \"second task\"'; exit $?"
  exit=0
